# 모바일 방문경로 최적화

스마트폰 브라우저에서 여러 방문지의 도로 기준 순서를 계산하고 지도와 방문순서표를 표시하는 단일 HTML 웹앱입니다.

## 저장소에 올릴 파일

저장소의 최상위 경로에 다음 파일을 그대로 올립니다.

- `index.html`
- `.nojekyll`
- `.gitignore`
- `README.md`

`API키.txt`는 절대 GitHub에 올리지 마십시오. TMAP API 키는 실행 후 화면 오른쪽 위의 `키 설정`에서 각 사용자가 직접 입력합니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 위 파일 4개를 저장소 최상위 경로에 업로드하고 커밋합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`의 Source를 `Deploy from a branch`로 선택합니다.
5. Branch를 `main`, 폴더를 `/(root)`로 선택한 뒤 저장합니다.
6. 잠시 후 표시되는 GitHub Pages 주소로 접속합니다.

배포 주소는 일반적으로 다음 형식입니다.

```text
https://GITHUB_ID.github.io/REPOSITORY_NAME/
```

## 사용 순서

1. `키 설정`에서 각 사용자의 TMAP API 키를 입력합니다.
2. 방문처명, 주소와 전화번호를 입력합니다.
3. 출발지와 도착 방식을 설정합니다.
4. `최적경로 계산`을 누릅니다.
5. 지도와 방문순서표를 확인합니다.
6. 각 방문지의 `N 네이버 내비` 버튼으로 네이버지도 내비게이션을 실행할 수 있습니다.
7. 지도를 원하는 크기와 위치로 조정한 후 `결과 이미지 저장`을 누르면 지도와 방문순서표가 JPG로 저장됩니다.

## 주의사항

- 이 사이트는 TMAP API와 OpenStreetMap 지도 타일을 사용하므로 인터넷 연결이 필요합니다.
- API 키는 HTML이나 GitHub 저장소에 포함되지 않습니다. `이 브라우저에 키 저장`을 선택한 경우에만 해당 브라우저의 저장소에 보관됩니다.
- 방문지 주소와 좌표는 경로 계산을 위해 TMAP 서버로 전달됩니다.
- 네이버지도 앱 연결 기능은 스마트폰에 네이버지도 앱이 설치되어 있을 때 가장 원활하게 작동합니다.
- 브라우저의 CORS 정책 또는 회사 네트워크 정책이 TMAP 직접 호출을 차단하면 경로 계산이 작동하지 않을 수 있습니다.
- 실제 차량 진입구, 중앙분리대, 좌우측 접근, 회전 제한 및 현장 교통통제를 확인하십시오.
